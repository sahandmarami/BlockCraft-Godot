## ✨ چه خبره؟ (تغییرات نسخه ۲ نسبت به نسخه Three.js)

نسخه ۱ با Three.js در مرورگر/WebView ساخته شده بود و مشکلاتی داشت. نسخه ۲ از صفر با موتور واقعی بازی‌سازی **Godot 4.7** بازنویسی شد:

| مشکل نسخه ۱ | راه‌حل در نسخه ۲ |
|---|---|
| 💀 حیوانات «فقط سرشان» پایین می‌افتاد | گرانش روی کل بدن اعمال می‌شود (CharacterBody3D) — باگ کاملاً رفع شد |
| 🎮 کنترل‌های سخت و گیج‌کننده | جوئی‌استیک مجازی + کشیدن انگشت برای نگاه + دکمه‌های بزرگ جدا برای شکستن/قرار دادن |
| 🧰 hotbar جا نمی‌شد و می‌پرید | hotbar جدید ۹ خانه‌ای پایین صفحه با آیکون واقعی بلوک‌ها |
| 🎨 تکسچرهای ضعیف | تکسچر پیکسل‌آرت جدید با AO (سایه‌زنی گوشه‌ها) + نورپردازی شب/روز |

**امکانات کامل:**
- 🌍 دنیای بی‌نهایت با تولید رویه‌ای (تپه، غار، درخت، گل، دریاچه، ساحل شنی، قله برفی)
- 🌞 چرخه کامل شب و روز با غروب نارنجی و آسمان شب
- 🐄 جانوران: گاو، گوسفند، خوک + 🧟 زامبی‌های شبانه که شکار می‌کنند!
- ⛏️ شکستن بلوک با نوار پیشرفت + قرار دادن ۹ نوع بلوک (سنگ، چوب، شیشه، آجر و…)
- ❤️ سیستم جان با آسیب سقوط و حمله زامبی + مرگ و تولد دوباره
- 💾 ذخیره خودکار دنیا (هر ۲۵ ثانیه) + دکمه «ادامه بازی»
- ✈️ حالت پرواز با دو بار زدن دکمه پرش
- 🔊 افکت‌های صوتی پروسیجرال (بدون فایل خارجی)

## 📲 نصب

1. از بخش [**Releases**](../../releases) فایل `BlockCraft-Godot-v2.0.apk` را دانلود کنید.
2. ⚠️ **اگر نسخه ۱ را دارید، اول آن را حذف (Uninstall) کنید** — کلید امضای نسخه ۲ جدید است و بدون حذف، نصب ممکن نمی‌شود.
3. فایل را باز کنید و «نصب از منابع ناشناس» را تأیید کنید.
4. بازی کنید! 🎉

> حداقل اندروید: **7.0 (API 24)** • معماری: arm64-v8a • مجوزها: **صفر** — نه اینترنت می‌خواهد نه چیز دیگری.

## 🎮 راهنمای کنترل

| عمل | روش |
|---|---|
| راه رفتن | جوئی‌استیک پایین-چپ |
| نگاه کردن | کشیدن انگشت روی بقیه صفحه |
| شکستن بلوک | نگه‌داشتن دکمه ⛏ (به سمت نقطه وسط) |
| قرار دادن بلوک | دکمه ▣ (بلوک انتخابی hotbar) |
| پرش | دکمه ⤒ |

| انتخاب بلوک | لمس خانه‌های hotbar پایین صفحه |
| توقف/ذخیره | دکمه ≡ بالا-راست |

## 🛠 ساخت از سورس

```bash
# پیش‌نیاز: Godot 4.7.x + Android SDK (build-tools 34) + JDK 17
# قالب‌های اکسپورت اندروید Godot نصب شده باشند

godot --headless --import .          # ایمپورت دارایی‌ها
godot --headless --export-release "Android" build/BlockCraft.apk
```

- فایل `export_presets.cfg` از قبل آماده است (پکیج: `com.sahandmarami.blockcraft`).
- کلید امضا (keystore) در دارایی‌های Release موجود است: `blockcraft.keystore`
  - alias: `blockcraft` — رمز store و key: `blockcraft2025`
  - ⚠️ این کلید را امن نگه دارید؛ هر کس کلید + رمز را داشته باشد می‌تواند آپدیت با امضای شما بسازد.
- تست بدون دستگاه (شبیه‌سازی headless):

```bash
godot --headless --path . -s res://tests/sim.gd
```

## 📁 ساختار پروژه

```
├── scenes/main.tscn        صحنه اصلی
├── scripts/
│   ├── main.gd             راه‌اندازی، آسمان/مه، ذخیره‌سازی
│   ├── world.gd            مدیریت chunk ها، ری‌کست وکسلی DDA
│   ├── mesher.gd           مش‌سازی چانک‌ها (حذف وجه‌های پنهان + AO)
│   ├── textures.gd         تولید تکسچر پیکسل‌آرت در زمان اجرا
│   ├── blocks.gd           تعریف بلوک‌ها
│   ├── player.gd           فیزیک دستی AABB، معدن‌کاری، پرواز
│   ├── mobs.gd             گاو/گوسفند/خوک/زامبی با گرانش کامل بدن
│   ├── hud.gd              رابط فارسی RTL: جوئی‌استیک، hotbar، قلب‌ها
│   ├── menu.gd             منوی اصلی با مکعب چرخان
│   └── sfx.gd              صداهای تولیدشده با کد
├── tests/sim.gd            تست شبیه‌سازی کامل (boot تا ذخیره)
└── assets/                 فونت وزیرمتن
```
